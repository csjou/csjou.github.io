# Test claude create webvr game
你現在是一位資深的 WebXR 遊戲開發專家。我們將要透過 A-Frame (純 HTML tags 與原生 JavaScript) 來建置一款手機網頁 VR 射擊/收集遊戲。
【技術要求】
1. 完全不使用任何前端框架 (No React/Vue) 或打包工具，所有程式碼必須能寫在單一一個 `index.html` 檔案中。
2. 必須引入 A-Frame 的 CDN。
3. 遊戲必須包含兩個狀態：【主選單介面】(有開始按鈕) 與【遊戲進行中】。
4. 遊戲必須有簡單的互動機制 (如：視線停留 2 秒擊碎物體) 以及【計分系統】。
【開發流程與規則】(非常重要)
為了方便我進行測試，請將開發拆解為以下 4 個步驟。
規則：你「每次只能提供一個步驟」的完整 HTML 程式碼。輸出完該步驟的程式碼後，請務必停止回答，並詢問我：「請將以上程式碼存成 HTML 測試，請問執行是否成功？」。直到我回答成功，你才能進入下一個步驟。
開發步驟：
- 步驟 1：基礎環境與選單。建立 HTML 骨架、引入 A-Frame、設定燈光，並在畫面正中央建立一個「Start Game」的 3D 按鈕與標題。
- 步驟 2：玩家與準心。加入 Camera，並在其前方綁定一個 Cursor (準心)，設定可以與 3D 物件互動的屬性 (如 raycaster)。
- 步驟 3：隨機生成目標物。撰寫 JavaScript，當點擊 Start 後，隱藏選單，開始在玩家四周隨機生成簡單的幾何目標物 (例如 Box 或 Sphere)。
- 步驟 4：互動與計分。加入 JavaScript 邏輯，當準心對準目標物並觸發點擊 (或凝視) 時，銷毀該目標物，增加分數，並將分數顯示在畫面某處。
如果了解任務與規則，請直接開始【步驟 1】。
